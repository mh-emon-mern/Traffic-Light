
## Traffic Light Project
<img width="414" height="659" alt="Screenshot 2026-05-13 at 4 54 10 PM" src="https://github.com/user-attachments/assets/471c8259-e387-4ebf-adb9-ea467ea45efb" />



This project demonstrates a simple **Traffic Light** built using only **HTML and CSS**.  
It shows three lights (Red, Yellow, Green) styled with CSS inside a black container,  
and includes a label below: *"This is Traffic Light"*.

The purpose of this project is to practice **basic HTML structure** and **CSS styling** concepts like:
- Creating shapes (circles, rectangles) with CSS.
- Using colors to represent real-life objects.
- Applying alignment and positioning techniques.

No JavaScript is used in this project. It’s purely static HTML & CSS.
